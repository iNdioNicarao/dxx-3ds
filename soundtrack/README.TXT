D1X-Rebirth - Soundtrack Pack
=============================
			by zicodxx@yahoo.de
			http://www.dxx-rebirth.com


This AddOn Pack will add a new version of the game's original Soundtrack to D1X-Rebirth. For an authentic gaming experience, all music was recorded with the Roland Sound Canvas SC-55 MIDI Module as they were meant to be heard in the 90s.
Recordings by Brandon Blume (shine62@gmail.com).

To install this pack, you will NOT need to extract this ZIP-file. Just copy this ZIP-file to the directory where your Descent 1 content resides (depending on the OS you use) and the game will use it automatically. If you want to remove this pack, just delete the ZIP and you are done.
